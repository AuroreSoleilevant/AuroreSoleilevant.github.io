# 项目不变量

这份文档记录在维护网站时不能被无意改变的事实。它不是限制创作内容，而是帮助我们在小步修改时保护已经公开的网站。

## 发布与路径

- 正式网站域名是 `https://auroresoleilevant.github.io/`。
- 网站从域名根路径发布。因此 `/css/...`、`/js/...`、`/histoire/...`、`/images/...` 这类以 `/` 开头的站内 URL 是公开 URL，必须保持有效。
- 当前通过提交并推送 `main` 分支发布。未经项目所有者明确批准，不改变部署分支、发布入口、GitHub Pages 设置或部署模型。
- `/SpicaRF/` 与 `/NELC_site/` 指向其他实验项目或子站，不是本仓库应解析的普通文件链接。

## 内容与 URL

- 已公开的页面 URL、文章 URL、作品 URL、章节 URL、标签和分页 URL 都是兼容性承诺。重构时不得改名、移动或删除，除非项目所有者明确批准并安排兼容方案。
- `histoire` 作品 ID 是稳定且唯一的主标识，同时用于作品目录名和 URL。
- 作品 ID 的语义命名规则是：`H` 加故事中文名每个汉字的拼音首字母。校验工具只检查基础格式（大写 `H` 开头，后续为大写英文字母）；它不会猜测中文到拼音的对应关系。
- 常规多章作品的章节 URL 与章节关系必须保持：作品首页为章节 `0`，其他章节使用连续数字目录。`json/histoire/<作品ID>.json` 是章节目录、上一章和下一章功能所依赖的数据。
- 常规章节作品和互动分支作品是两种不同结构：前者由章节 JSON 驱动，后者（目前为 `HHXLOYDCS`）由页面中的分支链接驱动。不能把其中一种规则强加到另一种上。

## 不得破坏的体验

- 桌面端以现有 1920×1080 的布局和行为为主要视觉基准；移动端以现有响应式布局为基准。
- 顶栏离开页面顶部后出现的半透明效果必须保留。
- 页脚进入与离场动画必须保留。
- 页面淡入淡出、图片加载、阅读进度、返回顶部、章节侧栏和章节导航都属于既有功能；未经明确批准，不得因“重构”改变它们。

## 技术边界

- 网站保持无框架静态网站。未经项目所有者明确批准，不引入 Hexo、Astro、React、Vue 或其他运行时框架。
- 修改应小步、可验证、可回滚。每次新增作品、章节、URL 或移动资源后，先运行 `node tools/verify-content.mjs`，再进行人工视觉检查。
- 开发辅助工具可以新增，但不得改变网站发布文件的 HTML 输出、CSS、JavaScript 行为、视觉效果、URL 或部署方式。
