# 开发检查说明

## 环境

本仓库的内容校验工具只使用 Node.js 内置模块，不需要安装任何依赖。

- 推荐 Node.js：`>= 20`（当前开发环境为 Node.js `v24.18.0`、npm `12.0.1`）
- 不需要运行 `npm install`。

## 运行校验

在仓库根目录执行：

```powershell
node tools/verify-content.mjs
```

退出码含义：

- `0`：没有发现错误。仍应在影响视觉或交互的改动后执行人工视觉回归清单。
- 非 `0`：发现内容、章节、资源或站内链接错误。请阅读脚本输出并人工修复源文件；脚本不会自动修复任何内容。

以下情况应运行该命令：新增作品、新增章节、修改 URL、重命名目录、移动图片/音频/脚本/样式资源，或更新列表 JSON 后。

## 当前范围

- 当前未接入 GitHub Actions；校验命令仅供本地或命令行使用。
- 当前未引入自动截图测试；视觉检查请按 [visual-regression-checklist.md](visual-regression-checklist.md) 手工执行。
- 校验工具只读，不写入仓库，也没有自动修复模式。
