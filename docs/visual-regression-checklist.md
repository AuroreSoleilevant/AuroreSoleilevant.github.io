# 人工视觉回归清单

本清单用于每次修改后人工确认网站外观和交互没有回归。当前不使用自动截图工具。

## 视口

每次至少检查下列视口；桌面端优先以 1920×1080 为基准。

| 视口 | 重点 |
| --- | --- |
| 1920×1080 | 主要桌面视觉基准、内容宽度、顶栏和页脚 |
| 1366×768 | 常见笔记本电脑布局 |
| 390×844 | 常见手机竖屏布局 |
| 360×800 | 较窄手机竖屏布局 |

## 代表页面类型

至少打开并检查：

- 首页：`/`
- 普通文章页：`/article/131025A/`
- 作品列表页：`/histoire/`
- 常规作品首页：`/histoire/HWAYJ/`
- 常规章节页：`/histoire/HWAYJ/1/`
- 长章节和章节侧栏：`/histoire/HWAYJ/14/`
- 恐怖主题页：`/histoire/HHXLOYDCS/Q1/`
- 互动作品分支页：`/histoire/HHXLOYDCS/Q16/`
- 标签或分页页：`/tag/fini/` 和 `/tag/fini/2/`
- 实验室页面：`/laboratoire/`

## 每页检查项

- [ ] 字体、行距、间距、内容宽度和对齐与基准一致。
- [ ] 顶栏在页面顶部时外观正确。
- [ ] 向下滚动后，顶栏仍显示既有的半透明效果。
- [ ] 页脚在进入页面时正常进场；点击同站链接离开时保留既有离场效果。
- [ ] 页面淡入淡出没有闪白、长期空白或重复动画。
- [ ] 图片正常加载，失败时页面布局不明显跳动。
- [ ] 长页面的返回顶部按钮可见、位置正确且可用。
- [ ] 长页面的阅读进度条正常更新。
- [ ] 常规多章作品的章节侧栏能打开、关闭、定位当前章节。
- [ ] 常规多章作品的“上一章 / 章节目录 / 下一章”链接和按钮正确。
- [ ] 互动作品的每个已点击分支仍能到达正确页面。
- [ ] 手机视口没有横向溢出；导航、卡片、文字和按钮可操作。
- [ ] 文本内容、公开 URL 和浏览器前进/后退行为没有改变。

## 建议顺序

1. 先运行 `node tools/verify-content.mjs`。
2. 按上面的视口与代表页面进行人工检查。
3. 若发现回归，记录 URL、视口、浏览器、操作步骤和截图，再决定是否继续修改。
